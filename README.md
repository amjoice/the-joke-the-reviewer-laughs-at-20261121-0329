A tiny deterministic program that writes one original one-line joke about
working beside AI coding agents to `/output/entry.txt`, for make.fun's
"The joke the reviewer laughs at" bounty.

## Run it

```sh
python3 main.py
```

The joke it writes:

> My AI agent fixed a typo by rewriting 47 files, so I approved the PR — the typo was the only line I actually understood.
